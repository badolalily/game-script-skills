# 输出示例结构

用于用户要求“直接给可对接稿”或“做成模板”时的最小结构。内容应替换为用户项目资料，不要照抄示例占位。

## 一、项目基础信息

| 项目 | 内容 |
|---|---|
| 项目 | 【项目名 / 素材名】 |
| 素材类型 | 手机游戏 Playable 演示 / 可互动广告 |
| 视频比例 | 竖屏 9:16 |
| 总时长 | 约【15秒】 |
| 美术风格 | 【风格描述】 |
| 核心体验 | 玩家通过【操作1】->【操作2】->【操作3】完成体验 |
| 正确选择或正确操作 | 【正确角色 / 正确按钮 / 正确拖拽目标】 |
| 主要卖点 | 【卖点】 |
| 制作依据 | 用户提供 brief / 参考图 / 录屏 / 广告简化假设 |
| 时间口径 | 时间码用于演示视频；真实 Playable 在交互节点等待玩家输入；无操作提示只引导，不替玩家完成关键选择。 |

## 二、核心制作规则

1. 【角色或物件】从出现到结束必须保持一致。
2. 【角色A】固定对应【技能A】，【角色B】固定对应【技能B】。
3. 正确答案只能是【正确项】。
4. 点击后只能展开【图标/面板/反馈】，不能重绘角色或生成第二个角色。
5. 战斗中【主角位置】、【敌人位置】、【攻击方向】必须保持一致。
6. 禁止【项目专属禁止项】。

## 三、Playable主路径

玩家进入画面 -> 【危机/目标出现】 -> 【点击查看】 -> 【识别正确选择】 -> 【拖拽/放置/点击确认】 -> 【系统状态变化】 -> 【进入战斗】 -> 【释放技能】 -> 【胜利反馈/CTA】

## 四、分镜脚本表

| 镜头号 | 时间安排 | 镜头截图 | 镜头内容 | 玩家操作与反馈 | 屏幕文案 | 制作重点 |
|---|---|---|---|---|---|---|
| 1 | 0-2s | 【截图待补：描述构图】 | 【开场危机和核心物件状态】 | 无操作；系统展示危机。 | 【开场文案】 | 明确空间方向、主物件初始状态。 |
| 2 | 2-4s | 【截图待补】 | 【可选项 / 按钮 / UI 出现】 | 玩家可点击【目标】；无操作时手指演示。 | 【操作提示】 | 可操作区清楚，触控目标足够大。 |
| 3 | 4-7s | 【截图待补】 | 【逐个查看或做出选择】 | 点击后出现【反馈】；错误项展示原因。 | 【技能/反馈文案】 | 点击不改变原角色或原物件。 |
| 4 | 7-9s | 【截图待补】 | 【拖拽 / 放置 / 确认】 | 拖到【目标区】并松手；成功吸附，失败回弹。 | 【拖拽提示】 | 起点、终点、吸附圈、松手条件清楚。 |
| 5 | 9-12s | 【截图待补】 | 【状态变化 / 起飞 / 转向 / 装备生效】 | 可自动播放或等待点击。 | 【状态文案】 | 状态变化完整可见，不能靠切镜隐藏关键动作。 |
| 6 | 12-15s | 【截图待补】 | 【战斗 / 技能释放 / 结果】 | 点击【技能按钮】；命中敌人弱点。 | 【战斗反馈】 | 攻击方向、敌我位置、技能归属正确。 |

## 五、交互逻辑说明

1. 点击逻辑：【点击对象】->【展开/高亮/反馈】->【状态是否变化】。
2. 拖拽逻辑：起点为【对象】，终点为【目标区域】，进入【命中范围】并松手判定成功。
3. 错误输入：【错误对象/空白区域】显示无效反馈，不改变关键状态。
4. 重复输入：重复点击当前对象只重播反馈或保持面板，不叠加生成新对象。
5. 无操作：停留当前可操作状态，按提示层级增强引导。
6. 状态继承：【选择结果】必须延续到后续镜头。

## 六、无操作引导

| 触发条件 | 引导表现 |
|---|---|
| 2秒无操作 | 可操作目标轻微跳动或按钮光圈扩散 |
| 4秒无操作 | 目标高亮，路径虚线或下一步区域呼吸 |
| 6秒无操作 | 半透明白色手指演示一次操作，不自动完成最终选择 |

## 七、美术、动画与程序验收

- 角色与 UI：【角色/卡牌/按钮】外观一致，不能点击后变脸、换装、换色或重绘。
- 交互反馈：点击波纹、面板展开、正确标记、错误回弹、吸附圈齐全。
- 空间连续性：敌我上下关系、移动方向、攻击方向、镜头切换前后状态一致。
- 技能归属：【正确技能】只能由【正确角色/物件】触发。
- 禁止项：真实人手、水印、随机 Logo、乱码、镜像翻转、重复角色、错误技能串位。

## 八、建议埋点

| 事件 | 触发时机 |
|---|---|
| playable_start | 素材开始 |
| first_interaction | 玩家首次真实触摸 |
| option_view | 玩家查看某个选项 |
| correct_select | 玩家选择正确项 |
| drag_start | 开始拖拽 |
| drag_success | 拖拽成功 |
| drag_fail | 拖拽失败 |
| skill_click | 点击技能按钮 |
| battle_success | 战斗成功 |
| cta_click | 点击下载或跳转 |

## 九、模板复用说明

下次复用时替换【项目名】、【角色与技能】、【正确选择】、【敌人弱点】、【操作路径】、【时间码】、【屏幕文案】、【验收红线】和【CTA】。本项目专属设定不要默认带入其它游戏。
